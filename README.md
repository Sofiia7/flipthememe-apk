# FlipTheMeme for Android

Call the next 60 seconds of a Solana meme coin from your phone: UP or DOWN, matched 1 to 1 against other players, a win pays 1.96x the matched part. Runs on Solana devnet with test SOL only.

**Install**

1. Download `FlipTheMeme.apk` from the [latest release](https://github.com/Sofiia7/flipthememe-apk/releases/latest), or open https://sol.flipthememe.com/get on the phone.
2. Open the file. If Android asks, allow your browser to install apps.
3. Switch your wallet to devnet (Seed Vault Wallet: Settings, Network, Devnet; Solflare works too) and open FlipTheMeme. Tap UP or DOWN: the app asks the wallet once, tops up and opens a session.

Each release lists the sha256 of the file. This repository holds only the builds.
